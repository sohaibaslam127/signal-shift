# Signal Shift

*Connect the signal. Outsmart the grid.*

A portrait 2D logic-puzzle game for Android and iOS, built with Godot 4.7 and GDScript.
Rotate circuit tiles to route power from the source to every receiver.

- 60-level free campaign (6 chapters), 90 bundled daily puzzles, 20-level Overclock pack
- Undo, reset, hints, stars by par, move-limit levels
- Offline, no accounts; ads and purchases behind service interfaces (no SDK installed yet)

## Run

Open the folder in Godot 4.7.2 and press Play, or:

```sh
godot --path .
./tools/run_tests.sh        # 62 tests + headless boot smoke run
```
