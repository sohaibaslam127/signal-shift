# AGENTS.md — Signal Shift

Guidance for coding agents (Claude Code, Google Antigravity) working on this repository.

## Project

- Godot **4.7.2** Standard, GDScript only. Portrait 2D puzzle game for Android and iOS.
- Specification: `docs/SPEC.md`. Milestones and status: `docs/MILESTONES.md`.
- Renderer: Compatibility (OpenGL ES 3 / WebGL 2 class) for the widest device support.

## Commands

```sh
# Re-import resources and refresh the global class cache (run after adding class_name scripts)
godot --headless --path . --import

# Run import + tests; also fails on any SCRIPT ERROR (preferred)
./tools/run_tests.sh

# Run only the test runner (exit code 0 = all passed)
godot --headless --path . -s res://tests/run_tests.gd

# Regenerate the UI theme resource
godot --headless --path . -s res://tools/build_theme.gd

# Regenerate and verify puzzle content (campaign, daily, packs)
godot --headless --path . -s res://tools/generate_levels.gd
```

## Architecture rules

- Gameplay rules live in pure `RefCounted` classes under `scripts/gameplay/` and `scripts/data/` (`TileTypes`, `BoardState`, `SignalSolver`, `PuzzleData`, `PuzzleValidator`, `ProgressionData`). They never touch nodes, so they are unit-testable headless.
- Views (`CircuitTile`, `PuzzleBoard`) render from model data. Never derive connectivity from node positions.
- Autoloads (`scripts/core`, `scripts/services`) have no `class_name` (the autoload name is the global).
- Platform SDKs (ads, billing) are only reached through `AdsBackend` / `PurchaseBackend` implementations. The game must run with the null backends.
- Never simulate a successful real-money purchase. Entitlements come only from the purchase backend.
- Puzzle content is JSON under `resources/puzzles/`. It is generated by `tools/generate_levels.gd`, which refuses to write any puzzle that fails `PuzzleValidator`. Edit the generator's level specs rather than hand-editing JSON, or run the test suite after hand edits.

## Conventions

- Static typing everywhere practical. Tabs for indentation (Godot default).
- Tests: `tests/test_*.gd` extending `res://tests/test_case.gd`; methods named `test_*`. No third-party test framework.
- Do not commit `.godot/`, export credentials, keystores or signing files.
- Keep one agent per file at a time; coordinate before editing files another agent is changing.
